# 🎙️ Transcription Pipeline

Автоматизированный локальный конвейер для транскрибации и перевода медиафайлов. Инструмент извлекает аудио, оптимизирует его для экономии вычислительных ресурсов и переводит речь в текст с высокой точностью. Скрипт генерирует размеченные Markdown-файлы с тайм-кодами, которые служат идеальной базой для последующей бизнес-аналитики, саммаризации и подготовки субтитров.

## 🚀 Ключевые возможности

* **Мультиформатная пакетная обработка:** Поддержка автоматического парсинга директории с файлами `.mp4`, `.wav`, `.mp3`, `.mkv`, `.m4a`.
* **Аппаратная оптимизация (Low-RAM):** Встроенная предобработка через FFmpeg (конвертация в моно, даунсэмплинг до 16 kHz) и квантование модели Whisper до `int8`. Это позволяет обрабатывать многочасовые записи исключительно на CPU.
* **Мультиязычность и перевод на лету:** Автоматическое распознавание языка оригинала и возможность прямого перевода на английский язык (`task="translate"`).
* **Модульная архитектура подготовки данных:** Инструмент формирует чистые `.md` файлы с зашитыми системными инструкциями, полностью готовые к финальному этапу обработки через LLM (генерация Action Items, конспектов и статей).

## 💼 Примеры работы (Портфолио)

Данный пайплайн является основой для решения комплексных задач в трех нишах:

1. **[Корпоративный сектор] Протоколирование рабочих встреч:** Транскрибация шумных созвонов с последующим выделением смысловой выжимки и списка бизнес-задач.
2. **[EdTech] Саммаризация научных лекций:** Обработка многочасовых академических видео с выделением ключевых концепций.
3. **[Медиа] Подготовка мультиязычных субтитров:** Перевод и адаптация быстрых интервью с сохранением тайм-кодов.

*(Примеры итоговых PDF-отчетов доступны в папке `portfolio_examples/`)*.

## 🛠 Технологический стек

* **Язык:** Python 3.10+
* **ML Модель:** [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2)
* **Аудио-процессинг:** FFmpeg, `subprocess`
* **Архитектура:** CLI-утилита (`argparse`), локальная обработка без использования сторонних API.
